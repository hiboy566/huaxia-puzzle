# Feature 01：核心拼图与结算

## 需求

- [F-001] 用户能从中国特色图库选择图片和 12/24/48/80 片难度。
- [F-002] 用户能拖动拼片，正确位置自动吸附，错误移动不惩罚。
- [F-003] 系统记忆最近难度并显示收藏、完成状态。
- [F-004] 完成后可收藏、分享、重玩、下一幅或返回图库。

## 验收条件

- [AC-001] 首次进入从首页到 12 片开局不超过 3 次点击。
- [AC-002] 四档难度生成数量分别为 12、24、48、80。
- [AC-003] 重新打开难度选择时默认突出最近使用难度。
- [AC-004] 完成状态和收藏状态在刷新后仍保留。
- [AC-005] 结算页的下一幅能进入图库中的下一张图片。
