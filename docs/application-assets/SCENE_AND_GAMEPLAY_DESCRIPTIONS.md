# 巧拼雅集主要场景与整体玩法说明

> 以下内容用于微信小游戏、抖音小游戏申请或审核材料，每项均控制在 500 字以内。

## 申请字段：各主要场景描述（412 字）

巧拼雅集主要包含首页图库、难度选择、每日拼图、核心拼图、辅助菜单、完成结算及设置帮助等场景。首页展示游戏名称、熊猫、长城和传统风景等精选图片，以及收藏、完成次数、每日拼图和续玩入口；存在未完成记录时，玩家可直接恢复上次进度。选择图片后可进入难度场景，从12片、24片、48片和80片中选择，或参加当天固定的12片每日拼图。核心拼图场景采用横屏布局，中央为拼图区，右侧为待拼区，玩家拖动拼片至正确位置附近即可自动吸附，页面同步显示原图缩略图、完成进度和用时。辅助菜单提供免费提示、原图预览、整理未完成拼片及保存退出功能，额外提示或长时间预览由玩家自愿选择观看激励视频获得。全部拼片正确放置后进入结算场景，展示作品、难度和用时，并提供收藏、分享、重玩、下一幅和返回图库。设置场景支持音效、震动、减少动画、高对比轮廓、隐私协议和客服反馈。横幅广告仅出现在首页与结算页，插屏只在通关后的自然停顿按频率展示，核心拼图操作页不展示广告。

## 1. 首页与精选图库场景

首页是玩家进入游戏后的主要导航场景，整体采用清爽雅致的东方配色，展示“巧拼雅集”名称、每日拼图入口、设置入口和精选图库。图库以图片卡片形式呈现熊猫、长城和传统风景等主题内容，每张卡片包含主题名称、图片简介、推荐难度、收藏状态和历史完成次数，玩家点击卡片或“选择难度”按钮即可进入开局流程。如果本地存在尚未完成的拼图，首页会优先显示“继续上次拼图”入口，并标明已保存的图片与碎片数量，方便玩家快速恢复进度。首页底部可展示与游戏功能区明显区分的小广告，广告不会遮挡图片选择和操作按钮。游戏内容由运营方预先配置，不提供用户上传、公开评论、聊天或内容发布入口，避免产生用户信息展示和不适宜内容传播风险。页面根据不同手机屏幕宽高、安全区域和刘海位置调整内容间距，确保微信小游戏和抖音小游戏横屏运行时信息完整、按钮可点击。首页主要任务是让玩家快速了解内容、查看个人进度并在少量操作内开始或续玩，不设置复杂的账号注册流程。

## 2. 难度选择与每日拼图场景

玩家选中主题图片后进入难度选择弹窗，可从12片、24片、48片和80片四档难度中选择。12片和24片适合初次体验或碎片时间游玩，48片为标准挑战，80片适合希望获得更长拼图体验的玩家；系统会记住最近一次选择，并在下次进入时突出显示，减少重复操作。不同难度只改变图片切分的行列数量和待拼拼片数量，主题图片、基础操作和完成条件保持一致，不会通过随机数值提高失败概率。每日拼图以北京时间日期为依据，从现有主题中确定当天图片，并采用12片轻量难度，让玩家每天都能快速完成一次挑战。首次完成当日拼图后会记录当天印章，返回时可看到完成状态，也可以继续重玩，但不会影响基础玩法。每日内容直接取自已经配置并审核的图库，不产生用户上传内容，也不要求连续签到。该场景只负责说明目标和选择开局条件，不设置强制付费、体力消耗或倒计时压力，玩家可以随时取消并返回首页；选择难度后直接进入拼图，流程简单清晰。

## 3. 核心拼图操作场景

拼图场景采用横屏布局，中央为主要拼图区，右侧为待拼区，并保留菜单、主题名称、完成进度、用时和原图缩略图等信息。系统按照所选难度将完整图片切分为具有凹凸边缘的拼片，并以固定规则打乱至待拼区。待拼区中的拼片会适当缩小以节省空间，玩家按住后恢复正常比例并置于上层，便于观察和拖动。玩家用手指将拼片拖至中央棋盘，拼片接近正确位置时会自动吸附、固定并保持正确层级，配合可选的短震动提供明确反馈；位置不正确时仍可继续移动，不扣分，也不会导致失败。棋盘提供淡化原图、分区网格和清晰拼片轮廓作为辅助，完成数量、总数量和用时持续更新。拼片吸附后、每隔十五秒、切换后台或主动退出时都会保存本地进度，玩家再次进入可继续。系统会限制画布和待拼区范围，避免拼片因屏幕比例差异而无法找回。拼图操作页面不展示横幅或插屏广告，避免误触和干扰核心操作，玩家可专注完成还原目标。

## 4. 拼图菜单与辅助功能场景

玩家在拼图过程中点击左上角菜单，可打开不会丢失当前进度的辅助面板。面板提供继续拼图、使用提示、原图预览、将未完成拼片放回待拼区以及保存并退出等功能。每局提供一次免费提示，使用后系统自动将一块尚未完成的拼片放到正确位置；免费次数用完后，玩家可自主选择是否观看激励视频获得额外提示，每局最多使用两次广告提示，且两次之间保留必要间隔，未完整观看不会发放对应奖励。原图预览每天提供两次免费机会，每次短暂显示完整图片；免费次数用完后，每局可自愿观看一次激励视频获得十五秒预览。观看前均有明确说明和确认按钮，取消观看不会影响当前进度，广告加载或播放异常也不会阻塞基础游戏。待拼区整理功能只重排尚未完成的拼片，已正确吸附的拼片保持不变；保存并退出会记录当前用时、难度和拼片位置并返回图库。所有辅助功能都是降低观察和整理难度的可选工具，不改变完成判定，也不会形成强制消费或付费才能继续的情况。

## 5. 完成结算场景

当所有拼片均吸附到正确位置后，系统停止计时、显示完整原图并进入完成结算场景。结算页展示“拼图完成”、当前作品名称、所选碎片数量和本局用时，同时明确基础完成结果已经获得，不要求观看广告才能确认通关。系统会清除本局未完成存档，更新该作品的历史完成次数；若当前为每日拼图，还会记录当天印章。玩家可以收藏当前作品，收藏状态会保存在本地并同步展示于首页图库；也可以调用平台分享能力发送本次完成信息，分享不是领取奖励或继续游戏的前置条件。玩家可选择“再玩一次”以相同图片和难度重新开局，“下一幅”会切换至图库中的下一张主题图片并保持当前难度，“返回图库”则回到首页继续选择。结算阶段可在自然停顿位置按频率规则展示插屏广告，并在底部展示明确标注的横幅广告，但设置前三局保护、至少一百二十秒间隔、展示频率限制和失败熔断。广告展示失败时直接恢复结算操作，不影响基础结果、收藏、分享及后续按钮使用。

## 6. 设置、帮助与隐私场景

设置与帮助场景用于管理体验偏好和平台服务入口。玩家可分别开启或关闭音效、短震动、减少动画和高对比拼片轮廓，设置结果保存在本地，并在后续游戏中持续生效。高对比模式通过加强拼片边缘颜色帮助识别边界；减少动画适合希望降低动态效果的玩家；音效和震动均可独立关闭，避免在安静环境中造成打扰。页面提供隐私与用户协议入口，说明游戏仅保存完成拼图所需的本地进度、收藏、设置和匿名运行事件，不开放玩家上传图片、聊天、公开昵称排行或内容发布。平台登录、广告及客服能力只在相应功能被触发时调用，不在游戏中索取与核心玩法无关的信息。客服与反馈按钮使用微信或抖音平台提供的可用能力，在能力缺失时给出提示而不会卡住页面。设置页同时说明广告只用于附加提示和自然结算，不影响基础关卡与奖励。所有开关均使用清晰的“已开启”或“已关闭”状态表示，玩家修改后即时保存，完成设置后可直接关闭面板返回原场景。

## 7. 整体玩法设计

巧拼雅集是一款面向微信小游戏和抖音小游戏的轻量休闲拼图游戏，以熊猫、长城和传统风景等图片作为主题内容。核心循环为“选择图片—选择难度—拖动拼片—接近目标位置自动吸附—完成整幅作品—收藏、分享或挑战下一幅”。游戏不设置失败次数、体力值和强制倒计时，玩家可根据时间与熟练度选择12、24、48或80片，并通过本地自动保存随时中断和继续。难度只影响拼片数量，不影响图片获取和基础完成结果；所有拼片放入对应位置后即判定完成。每日拼图提供稳定的短时回访目标，收藏、完成次数和每日印章用于记录个人进度，但不要求连续登录。免费提示、原图缩略图、限次预览、待拼区整理和高对比轮廓用于降低观察与操作门槛。商业化遵循自愿、低干扰原则：额外提示与长时间预览采用玩家主动确认的激励视频，首页和结算页可展示明确标识的横幅广告，插屏只在完成后的自然停顿出现，核心拼图页不展示广告。整体设计强调易上手、无惩罚、可持续挑战、内容健康以及适配不同手机横屏尺寸。
