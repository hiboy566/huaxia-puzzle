# 巧拼雅集 MVP 产品需求

> 来源：`work/final3_pdf/中国特色拼图小游戏_PRD_V1.0.pdf`，版本 V1.0，2026-07-28。  
> 本文件是开发执行版；原 PDF 保留完整产品背景、指标、内容运营和 P1/P2 规划。

## 产品边界

- 仅发布到微信小游戏和抖音小游戏，使用 Cocos Creator 3.8.8 维护一套核心代码。
- 竖屏、无倒计时压力，以熊猫、长城、天安门等中国特色正版图片为内容。
- MVP 不包含多人、聊天、用户上传、云存档、120 片、旋转模式。
- 商业化采用 IAA：非操作页小广告、自愿激励视频、结算后低频插屏。

## P0 功能需求

| ID | 需求 | MVP 验收标准 |
| --- | --- | --- |
| FR-001 | 快速开始 | 首页展示 12 片推荐图，3 次点击内开局 |
| FR-002 | 图库与状态 | 展示主题、难度建议、收藏和完成状态 |
| FR-003 | 难度选择 | 支持 12/24/48/80 片并记住最近难度 |
| FR-004 | 拖动与吸附 | 拼片可拖动，接近正确位置自动吸附 |
| FR-005 | 画布辅助 | 支持画布复位；手势不导致拼片丢失 |
| FR-006 | 提示与预览 | 每局 1 次免费提示；每日 2 次免费预览，超额可看视频；广告失败兜底 |
| FR-007 | 自动保存与续玩 | 吸附后、每 15 秒、切后台和退出时保存，首页可续玩 |
| FR-008 | 结算 | 展示成图、用时、收藏、分享、重玩与下一幅 |
| FR-009 | 每日拼图 | 按北京时间选择每日图片，完成后记录当天印章 |
| FR-010 | 广告 | 首页/结算小广告；激励视频；前 3 局保护、之后每 3 局且间隔至少 120 秒的插屏 |
| FR-011 | 设置与客服 | 音效、震动、减少动画、高对比、隐私和反馈入口可用并持久化 |
| FR-012 | 埋点 | 启动、首页、选图、开局、吸附、退出、完成、广告、奖励和分享可统一上报 |

## 广告规则

- 拼图页禁止展示小广告；广告容器与功能按钮明显区分。
- 激励提示每局最多 2 次且间隔至少 60 秒；中途关闭不发奖。
- 预览每天前 2 次免费，之后每局最多 1 次激励预览，奖励 15 秒。
- 广告无填充、错误或超时不得阻塞，按广告位免费兜底。
- 同一广告位连续失败 2 次后熔断 10 分钟。
- 基础通关奖励不依赖广告。

## 存档与数据

- 本地保存 `puzzleId`、难度、固定 seed、拼片位置与完成状态、用时、提示状态和版本号。
- 收藏、完成状态、每日印章、最近难度、辅助设置跨局保存。
- 每日日期以北京时间（UTC+8）计算。

## 双平台与非功能要求

- 平台能力统一通过 `PlatformAdapter` 调用，所有 API 先做能力检测并有异常降级。
- 微信、抖音均构建成功；Web 仅作为本地预览环境，不作为发行平台。
- 目标：主流设备 55fps 以上，80 片可操作；资源失败可返回重试；广告返回后恢复游戏。
- 正式上线前必须替换平台广告位、接入隐私政策/用户协议/客服地址，并完成双平台真机测试。

## 内容要求

- 首个可运行版本内置熊猫、长城、天安门三幅图。
- 天安门等敏感内容上线前必须具备版权记录并完成人工复审。
- MVP 内置素材仅用于开发验收；正式商用前由发行方确认授权范围。
